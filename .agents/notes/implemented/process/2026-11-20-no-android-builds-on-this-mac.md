# Agent Note: 这台 Mac 不构建或安装安卓包

Status: implemented

## Problem

仓库曾把每轮 App 改动的安卓打包和真机更新视为交付条件。用户当前不验收安卓，并明确要求这台电脑不构建 Android。继续运行原路径会产生用户不需要的安装包，也会把安卓设备是否在线误当作当前交付的阻碍。

## Decision

[AGENTS.md](../../../../AGENTS.md)规定这台 Mac 不执行 Android 构建、打包或覆盖安装。不生成 APK 或 AAB，也不通过其他机器或 CI 代为完成当前任务未要求的安卓交付。按改动范围运行本机可执行的分析和测试。需要安卓交付时，先有用户的明确要求，并使用其他获准环境。

[后续修改同步手机](2026-11-05-verified-changes-to-phone.md)与本篇部分重叠；原签名兼容、数据保留及实际安装验证仍适用于获准交付。本篇不改变[公开发布](2026-11-04-github-mobile-release.md)的产物与签名协议，也不改变其他平台的授权要求。相关活跃笔记没有完全吸收或过时提案。

## Alternatives considered

- 仍在本机生成安卓包、只跳过安装，可以保留即取即用的产物，但与这台电脑不构建 Android 的明确要求冲突。
- 将默认构建转到其他环境可以保留安卓产物验证，但用户当前没有安卓交付需求，不能把禁止本机构建解释为授权远端代编。

## Consequences

Android 构建和真机在线状态不再阻塞本机 App 修改交付。本机的分析与组件测试不能证明安卓打包或真机行为；需要时，在明确授权的环境中另验，不将本机测试写作安卓验收。

# Agent Note: 聊天列表接入网页任务活动提醒

Status: implemented

## Problem

原生聊天列表只用标题粗细表示已读，没有展示运行中或完成未查看，也没有请求 Codex 网页使用的 `/api/activity`。因此网页已有绿色运行标记和蓝色完成标记时，App 仍显示普通卡片。另有会话菜单把列表 `archived: 0/1` 强制转换为布尔值，反复长按会将类型错误显示为通用操作失败。

## Decision

复用网页 `web/features/chat/activity.js` 的 `SessionActivity` 状态规则。已认证且前台时每五秒读取当前列表的活动，Codex 按执行主机批量请求 `/api/activity`，其他客户端复用包含活动字段的列表接口；活动读取不读取全部聊天正文、不恢复会话、不提交任务操作。通过已有受限资源接口接入 Rust，保持网关身份、客户端实例与主机隔离，并丢弃连接或列表变化后的迟到响应。

运行中显示绿点，已完成未查看显示蓝点，失败或停止未查看及待回应显示橙点，已观察任务断线显示灰点。首次取得的历史终态仅建立基线；观察到新 turn 的终态或已运行任务结束才产生未读。已读终态不会因临时缺少 turn 字段而重新提醒。提醒按网关身份与完整会话身份保存，只有实际可见且已加载的聊天清除完成提醒；隐藏标签或工作台不代为已读。沿用“活动状态”显示开关。

会话菜单只对 `true/false` 和整数 `0/1` 做标记转换，保留快照、列表、当前筛选的优先级。

## 记录归属

已检索活跃笔记中的会话菜单、活动、运行、完成与已读。[原生业务接入](../architecture/2026-11-10-native-web-parity.md)部分重叠，继续持有完整身份与业务读写边界；[手机界面](../architecture/2026-11-06-liquid-glass-mobile-ui.md)部分重叠，继续持有列表入口与视觉规范；[云读取恢复](../../proposed/bug-fix/2026-11-05-cloud-chat-recovery-and-notice-scope.md)部分重叠，继续持有连接恢复和错误归属。没有完全吸收或需要废弃的记录。

## Alternatives considered

- 从列表 `status` 和更新时间推断完成无需新增请求，但 Codex 列表缺少实时 turn 证据，也会把旧历史及停止误报为完成，因此采用网页的专用活动读取与终态标识。
- 对每条聊天轮询完整快照能够取得状态，但会重复拉取正文并产生大量请求，因此采用批量活动接口及其他客户端现有列表接口。
- 只画状态点改动最少，但状态无法随着任务结束自动更新，因此一并接入前台轮询、未读与实际可见性。

## Testing

`session_activity_test.dart` 覆盖运行到完成、首次与迟到历史不刷未读、失败/停止、断线、临时缺少 turn、持久化、可见聊天清除、真实标签隐藏后保留、网关身份和主机隔离、迟到响应及单批请求重入。`session_actions_test.dart` 使用真实曾返回的 `archived: 0` 先复现失败，再验证数字/布尔标记及快照优先级。Rust 两项新增回归核对批量 POST、CSRF、实例路由、原生终态、返回行过滤与非法参数；真实 FFI 和生产桌面 HTTP handler 夹具分别通过。

Flutter 全量检查为 433 项通过、4 项原生入口按既有条件跳过、14 项其他页面截图基线不匹配。独立检出 HEAD 后相同 14 项也失败，实际渲染图片逐字节相同，属于既有基线问题；本轮列表及菜单浮层的 4 项截图检查通过。Rust 首次全量的证书回归因 macOS 系统代理未到达 localhost 夹具而超时；仅为测试进程配置 localhost 的 `NO_PROXY` 后，完整 Rust 检查为 85 项通过、1 项专用夹具跳过，没有放宽产品证书验证。Clippy 与 Flutter 静态分析无问题。

220 个构建输入文件在模拟器构建前后哈希一致。iPhone 18 Pro / iOS 27.2 的签名 Debug 包覆盖安装后，Runner、Runner.debug.dylib 和 Dart 内核哈希与构建包匹配；重新查询安装后迁移的数据容器，5 个数据库/凭据元数据文件在首次启动前逐字节保留。真实界面保留云登录和两台电脑，当前聊天显示运行绿点，长按菜单正常展开；未发送或停止任务。蓝点流转由合成回归验证，没有为验收制造真实任务。证据保存在 `.tmp/session-activity-20261114/`。Android 构建入口因本机缺少 SDK/Java 配置而停止，ADB 也不可用，Lenovo 真机未更新。

## Consequences

聊天列表可以持续呈现网页同源的任务进展与未读终态。五秒刷新带来少量持续读取，慢请求期间不堆积同一列表的请求；连接或列表代次变化后的结果被丢弃，网络失败只能显示未知。每个网关/客户端/实例作用域最多保存 1000 条状态，共保留 20 个作用域；超出时淘汰最旧状态，重新出现的历史只建立基线。完成提醒依赖原生终态证据，首次观察到的历史任务不会全部标蓝。前台列表标记与系统推送是独立能力，此处不改变推送授权。

# Agent Note: 聊天加号打开独立工具标签

Status: implemented

## Problem

聊天栏的 `+` 直接打开合并工作台，且在选择时即加载文件目录。网页让用户先选文件、Git、终端、侧边聊天或子智能体；在 App 中后两项嵌在「派生任务」内，难以发现，用户也无法独立关闭或返回某一工具。

## Decision

聊天栏的 `+` 只显示「新标签页」玻璃弹窗。五项的顺序、标题和描述来自网页 `Workbench.newTab()`。缺少能力的项仍显示原因；Codex 的侧聊和子智能体遵循会话控制权限，其他客户端以 `tasks` 能力提供后台任务。终端在网关明确禁用时不可选；打开终端标签不等同于确认启动。

已打开的工具使用独立标签。重复选择同一工具只切换，不重新创建面板；关标签只释放本地视图和轮询。窄屏切换保留已挂载的聊天正文和草稿，宽屏保留聊天与所选工具并排。仅标签种类按电脑、客户端、实例、环境、会话与编码账号保存；重新进入先显示聊天，不预载其他面板。连接或账号变化废弃旧面板和未返回的选择，隐藏的终端和任务标签不继续发起轮询。文件链接和会话菜单的独立工作台入口继续沿用既有页面。

## 记录归属

[网页布局记录](../architecture/2026-11-15-web-client-ui.md)持有玻璃与聊天布局，本篇取代其中加号直达工作台的入口；[原生业务接入](../architecture/2026-11-10-native-web-parity.md)持有网关协议、写操作确认及完整会话身份。[最新消息首屏](2026-11-20-chat-opens-at-latest.md)与[滚动触发分页](../feature/2026-11-20-scroll-to-load-chat-history.md)持有正文规则，新标签不改变这些规则。会话菜单延迟、图片优化和电脑管理入口属于其他决定。未发现被完全吸收的记录或需否决的提案。

## Testing

`test/workspace_tabs_test.dart` 从聊天加号实际进入五项，覆盖延迟加载、能力提示、列表／详情读取、终端确认、侧聊创建／打开和账号切换；`test/ui_surface_layout_test.dart` 检查切回聊天后的正文位置。逐项目的同异及未验范围见[网页功能对照](../../../../docs/web-parity.md#聊天新标签页2026-11-20)。

`flutter test --no-pub` 为 603 项通过、5 项按条件跳过；三份界面回归合跑为 64 项通过，浅深色聊天与滚动仍使用原截图。桌面侧聊与子智能体回归 34 项通过；应用的实际 Rust FFI 连接桌面 HTTP Handler，验证临时 Git 仓库、文件传输及合成终端、侧聊请求回执。iPhone 18 Pro 模拟器签名包已覆盖安装并启动，启动前 4 个数据库及云元数据文件哈希一致，安装二进制与构建产物一致。模拟器只验证安装和启动，五项点击覆盖属于 Flutter 夹具，不代指真机或真实业务写入。本轮未构建 Android。

## Alternatives considered

- 在弹窗选完后继续使用旧工作台，只更改内部初始选项：改动较小，沿用内部页签偏好；但外层仍只有「工作台」，不能像网页那样独立关闭和保留工具，也会继续把两种任务入口混用。
- 直接嵌入网页工作台：可以继承网页的临时侧聊和分屏配置；但会引入另一套认证、草稿和终端状态，与 App 已有的 Rust 身份检查和原生文件保存入口重复。

## Consequences

加号不再默认发起文件读取，工具切换不重置聊天。为保留面板状态，已访问的工具在当前会话内持续挂载，关闭时才销毁。新标签偏好与旧独立工作台的索引分开存放，不迁移旧索引。网页主机目录浏览、临时侧聊、子会话标签和子智能体浮窗不是此次交付；实际 PTY、系统文件保存和跨设备使用仍需对应环境验证。

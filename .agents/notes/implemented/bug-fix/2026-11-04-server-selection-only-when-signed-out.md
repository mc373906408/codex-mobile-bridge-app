# Agent Note: 退出登录后才能选择云服务器

Status: implemented

## Problem

用户指出云服务中心在登录后仍显示整块“云端服务器”，要求只在退出登录后切服。底层 `CloudViewModel.switchServer` 已拒绝登录态切服，但页面仍能通过“退出并切换”的对话框代为退出，与期望的先退出、再选择流程不一致。

## Decision

`CloudServicePage` 已登录时完全移除服务器选择卡片；普通未登录页继续显示官方云和自部署选项。已保存连接的服务器信息可以显示，但登录态不提供“切换到此服务器”。所有页面切服回调（含旧回调和先前打开的输入框返回值）再次检查登录态，隐式 signOut 分支及不用的对话框翻译已删除。退出登录进行中不允许操作，完成本机退出后才恢复选择入口；底层 `switchServer` 的登录态拒绝保持有效。

手机使用同开发签名覆盖安装，保留当前 schema v3、账号、绑定及推送同意；上次部署的旧 v2 一次性清理不重复执行。页面变更不替用户退出登录或切换真实服务器。

## 记录归属

检索 proposed/implemented/rejected 后，没有现有笔记持有“登录后继续显示选择卡片/代为退出”的界面决定。[架构省察](../architecture/2026-11-04-app-architecture-and-scope-audit.md)部分重叠，继续持有账号和服务器作用域边界；[手机部署](../process/2026-11-04-current-schema-phone-deployment.md)保存上次 v2 初始化的历史，本次仅覆盖安装。本篇持有当前页面行为及回调防护。

## Alternatives considered

- 保留卡片并禁用按钮能解释服务器不可切换，但用户明确要求登录后不显示整块内容，故只在未登录时提供选择。
- 保留“退出并切换”确认可少一步操作，但仍让切服动作代为退出；采用独立退出按钮，退出后再选择。

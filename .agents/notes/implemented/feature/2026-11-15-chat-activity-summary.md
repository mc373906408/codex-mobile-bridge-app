# Agent Note: 聊天过程合并为可展开的活动摘要

Status: implemented

## Problem

每条思考、命令与工具调用即使收起仍占一行，长任务会让过程标题铺满手机屏幕。用户要求使用一条简短摘要，展开后以单行命令列表呈现，并在运行中提供动效；消息复制还缺少成功确认，右侧菜单及其中的选择引用入口不再需要。原生重连次数以多个助理或错误记录传来，导致手机重复绘制 CODEX 标题、正文和操作区；用户要求像客户端一样只显示一行最新次数。

## Decision

Flutter 展示层按相邻活动与相同 `turnId` 分组，外层默认收起，摘要依据实际类型显示思考、文件、命令或工具。用户消息、助理正文和错误始终是分组边界；不合并不同轮次，不改变原始消息、分页或写操作。已有思考和过程显示偏好先筛选内容，隐藏条目不出现在摘要里。

展开组后，每个命令以图标、执行状态和一行省略预览显示；点击具体条目才查看输出、图片或完整内容。原消息 ID、版本核对、完整读取及复制／引用入口继续复用。外层展开状态按当前会话和账号隔离，以组内消息 ID 维持，追加实时条目和载入较早内容不会主动关闭已展开的组。

只对前台、已认证实时连接中正在运行的当前末尾组播放呼吸动效；已有终态或不同 `activeTurnId` 的历史组不冒充当前任务。尚无活动的运行阶段显示独立思考状态。动画由标签自己的 controller 驱动，不触发模型刷新；任务结束、页面不可见或系统减少动态效果时停止。待审批时不播放运行提示，不用虚构时长或成功状态填补缺失的原生证据。

消息复制在完整内容及身份核验完成、剪贴板写入成功后才将按钮显示为“已复制”，两秒后恢复；读取或剪贴板失败仍使用既有错误提示。删除消息右侧更多菜单及选择文字引用页面，保留直接引用、原生编辑和分支入口。

重连状态也是展示投影：仅将未截断、无附件和额外输出、整行匹配 `Reconnecting... n/m`（含省略号和中文变体）的助理或错误记录识别为状态。相邻状态即使底层重试创建了新的轮次，只要总次数相同、当前次数未回退就合并；新轮次会更新合并行的活动身份。只显示网络图标与“正在重新连接 n/m”，不显示 CODEX 标题和消息操作。用户消息、正文、实际错误、工具活动、次数回退或总数变化均中断合并。原记录与分页游标不变，末尾当前轮重连复用运行标签动效，不同时叠加独立思考指示，也不猜测恢复成功。

## 记录归属

工具详情展开后的图片读取与渐进预览由[聊天附件缓存](../bug-fix/2026-11-20-chat-image-cache-and-preview.md)持有；折叠时不读取图片的边界不变。

检索活跃记录中的思考、过程、折叠、复制、活动和动效后，[网页布局](../architecture/2026-11-15-web-client-ui.md)部分重叠，继续持有页面布局及玻璃，此处持有活动聚合；[原生业务接入](../architecture/2026-11-10-native-web-parity.md)部分重叠，继续持有完整读取与身份校验；[列表活动提醒](../bug-fix/2026-11-14-session-activity-indicators.md)只持有列表未读状态，不与聊天内过程合并。[有界更新](../bug-fix/2026-11-06-bounded-chat-updates.md)继续持有原始分页，[最新消息首屏](../bug-fix/2026-11-20-chat-opens-at-latest.md)持有阅读位置。重连关键词命中的[连接恢复与错误清理](../bug-fix/2026-11-04-relay-response-completion-and-recovered-errors.md)和[云聊天恢复提案](../../proposed/bug-fix/2026-11-05-cloud-chat-recovery-and-notice-scope.md)持有真实链路恢复，不属于本次状态展示合并。其他命中涉及网络、通知或构建，与展示聚合无关；没有完全吸收或应废弃的记录。

## Alternatives considered

- 保留逐条折叠最容易定位工具，但仍让许多空标题占满屏幕，因此增加外层摘要并保留逐条详情。
- 将整轮全部内容合并能得到最短页面，但会藏起助理回复或错误并改变时间顺序，因此仅合并连续的活动。
- 通过定时器刷新整个聊天可以实现运行提示，但会重复处理正文和阅读位置；动效只重绘当前标签，并遵循可见性和系统设置。
- 一点击复制就显示成功最及时，但慢速完整内容读取或剪贴板失败时会给出假回执，因此等待实际写入完成。
- 在传输层删除旧重连消息可以减少记录数量，但会修改原始身份和分页；选择保留原记录，仅在展示层合并严格匹配的状态，不通过泛化关键词隐藏正文或错误。

## Testing

回归入口为 `test/activity_summary_test.dart`：覆盖分组及轮次边界、显示偏好、两级展开、流式追加保留展开、重连状态完整匹配／次数更新／跨重试轮次／边界隔离、旧轮次不动画、运行／结束／减少动态效果／隐藏标签，以及中英文复制回执和失败分支。活动与重连专项 18 项通过，浅深色截图检查通过；最终完整 Flutter 回归 508 项通过、4 项条件原生跳过，静态分析无问题。

联网锁定依赖快照核验因依赖站 TLS 握手失败，使用同一锁定依赖离线核验通过，未改锁文件。最终 iOS 模拟器 Debug 构建通过，构建前后 229 个输入哈希不变；覆盖安装保留 5 个持久文件且无变化，安装包与构建包关键二进制哈希一致，启动成功。真实聊天确认展开活动显示单行命令预览、复制后显示“已复制”、消息级 `…` 不存在；原生重连错误记录显示为单行网络图标与“正在重新连接 5/5”。最后补入的跨重试轮次身份更新由专项测试验证，并编入最终安装包；运行脉冲的停止与可见性通过 widget 测试，不以静态截图代替动效验证。Android 构建因本机没有 Android SDK、Java 和 ADB 未执行。

## Consequences

长过程在默认视图只占一条摘要，命令预览及详情仍可访问。分组依赖已加载内容；缺少轮次身份时只按相邻条目归组，分页前的未加载活动不会伪造进摘要。展开大量已加载条目仍有渲染开销，折叠时不构建它们。后台和离线停止动效仅是展示状态，不停止或恢复真实任务；复制确认不改变剪贴板与消息身份权限。

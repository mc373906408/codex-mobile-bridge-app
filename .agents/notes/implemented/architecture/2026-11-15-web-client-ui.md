# Agent Note: 原生界面对齐客户端网页布局

Status: implemented

## Problem

用户指出模型下拉框排布不佳且获取模型缓慢，随后提供客户端网页的模型面板与完整聊天截图，明确要求检查所有 UI 并复刻网页界面。现有 App 的悬浮玻璃、圆形输入操作、卡片化过程记录与网页的固定标题、工作台页签、紧凑正文和分层输入操作存在系统差异，单改弹窗不能满足目标。

## Decision

以相邻桌面仓库 `web/shared/presentation.css`、`web/shared/presentation-controls.css`、`web/layouts/compact/` 和功能 CSS 为布局来源，保留 Flutter 与 Rust 业务适配。用户进一步明确“材质还是玻璃设计”，因此原生玻璃能力、低透字的 regular 材质及无障碍实色降级继续适用；网页的页面层级、靛蓝、细边框与 9–14 像素控件圆角用于内容和表单。聊天改为固定玻璃标题、聊天／工作台标签、轻量活动折叠、模型身份及时间、底部玻璃工具区内的模型／Skill／权限／上下文工具、独立输入框和发送方式／工作模式／停止／发送行。根导航与电脑、登录、列表、设置以及业务管理页复用同一主题和玻璃导航栏。

模型面板使用有界可滚动单选列表、更新日期、强度网格、顶部刷新与关闭、整行应用，保留各 provider 的手动输入与 Fast 能力。模型目录按连接代次、完整会话、账号、目录身份和工作目录进行内存缓存并合并在途读取；已加载的当前快照替代读取前的重复正文请求，读取后仍核对远端账号。打开已认证可用聊天后预取，失败不阻断聊天。缓存仅用于展示，写入继续走原生即时身份／控制令牌核验和未知写入记录。

Skill 的输入栏与聊天设置入口共用 `skillPickerDialog`：居中 regular 玻璃弹窗采用透明遮罩，顶部为标题、关闭、选择说明和搜索，列表展示左侧复选框、名称与描述，底部固定刷新及完成。正常高度仅列表滚动；键盘、横屏或大字号时中间区域整体滚动，关闭及完成始终可达。勾选即时写入当前聊天草稿，最多八个，关闭和完成均保留选择并回到原页面，不发送消息。搜索输入防抖 200ms，迟到结果按请求代次丢弃，刷新与分页不清除选择；会话或账号变化后旧弹窗不能修改新草稿。保留原有目录读取前后身份核验。

权限采用同一玻璃弹窗，展示预设说明与当前选中；输入栏显示当前档位。普通桌面和 Linux／CLI 的读取差异、保存确认及其他 provider 的模式协议由[权限运行时面板](../bug-fix/2026-11-16-session-permission-runtime-picker.md)持有。

## 页面审计范围

连续思考和工具活动的进一步收起、单行命令预览、运行呼吸动效及消息复制回执由[活动摘要](../feature/2026-11-15-chat-activity-summary.md)持有，取代过程条目始终逐条出现在正文中的展示；页面布局和模型目录规则继续适用。

`lib/ui/` 的根电脑／云登录／连接选择／配对／通知／隐私页归 App 独有流程，采用网页主题但保留必要的手机入口。聊天列表、筛选、客户端切换、聊天正文、工具活动、消息操作、附件、模型、创建会话、权限／目标／队列／Skill、工作台文件／Git／终端／派生任务、账号／WSL／网关设置、预览、外观和通用选择／确认弹窗均逐族对照网页源。对应细节和验证缺口记录于 `docs/ui-parity.md`，不得仅凭主题通过声称所有业务页逐像素相同。

## 记录归属

已检索活跃 UI、玻璃、模型、目录及身份记录。[苹果界面](2026-11-06-liquid-glass-mobile-ui.md)、[清透玻璃](2026-11-06-native-clear-glass.md)及[可读玻璃](../bug-fix/2026-11-15-readable-chat-glass.md)的聊天覆盖式布局部分被本篇取代，各自的导航生命周期、原生装饰边界、regular 玻璃及历史取舍保留。[原生业务接入](2026-11-10-native-web-parity.md)部分重叠，继续持有完整身份、写前校验和业务协议；本篇仅改变表现与展示缓存。[已认证聊天能力](../bug-fix/2026-11-11-authenticated-chat-capabilities.md)部分重叠，继续以网关已授权能力决定功能可用性。没有完全吸收或需要废弃的记录。

## Alternatives considered

- 只修模型面板改动小，但用户明确扩大到整体 UI，无法修复聊天与网页的整体差异。
- 直接嵌入整套远端网页可自然同步 CSS，但会改写原生账号、Noise/P2P、文件与通知的业务桥，以及原先确认的原生界面方向，因此仍使用现有 Flutter 适配。
- 每次打开重新拉目录与正文容易实现即时核验，但复读长正文延长等待；预取与有界缓存减少重复读取，远端写入仍重新核验。
- Skill 使用独立页面可获得更多列表空间，但用户要求选择时保留聊天背景；有界弹窗通过中间区域滚动适配键盘和大字号，沿用网页勾选即保存草稿的行为。

## Testing

Skill 弹窗由 `test/skill_picker_test.dart` 检查输入栏和设置页两个入口、原聊天保持挂载、搜索和刷新保留最多八个选择、迟到响应隔离、键盘改变高度后搜索文本保留及中英文窄屏布局。与权限面板共 20 项专项通过，当前完整 Flutter 回归 528 项通过、4 项条件原生跳过；静态分析通过。原生模拟器已核对真实 Skill 列表、搜索筛选、完成关闭和权限三档勾选；当前构建与保留数据的安装结果见[权限面板验收](../bug-fix/2026-11-16-session-permission-runtime-picker.md)。

模型面板的浅深色截图、横竖屏／中英文／两倍字号／键盘检查通过；目录预取、在途复用、五分钟内不再请求、强制刷新、失败不阻断聊天、远端账号／目录身份变化、主机／实例／会话隔离及后台迟到响应有独立回归。请求计数验证当前聊天冷读取只保留一次读后快照，缓存命中不请求目录或正文；不据此宣称上游冷获取已有固定耗时。

根电脑、会话列表／客户端菜单、聊天、设置、直连登录、添加和重命名及长正文共十八张浅深色截图与模型面板两张截图通过。新业务布局回归实际点击工作台标签，覆盖文件、Git、终端、派生任务、聊天设置、Skill、队列、客户端管理、账号、WSL、网络和通知表单及新建会话的中英文窄屏大字号；终端工具栏改为横向滚动，任务切换用可换行选项组，WSL与创建表单补足字段间距。工作台与聊天切换保留同一正文滚动区和阅读偏移。所有检查均不发送真实消息、执行命令或修改真实账号。

截图夹具在真实异步区等待客户端图标解码，避免 `pumpAndSettle` 只等待帧而偶尔漏画图标；模型更新时间使用固定本地日期构造时间戳，跨时区仍显示相同文字。失败差异图仅保存在忽略目录。原生 FFI 的八项回归与一项生产桌面 HTTP handler 联调独立执行，覆盖全量 Flutter 默认跳过的原生入口；Rust 为85项通过、1项专用夹具跳过，构建脚本94项通过。最终复核日志位于本机 `.tmp/review-all-20261115/`。

首次整页对齐验收为490项Flutter通过、4项原生入口按条件跳过，静态分析无问题；27项业务布局与阅读位置回归均实际命中目标控件。228个构建输入在锁文件校验与构建前后哈希一致，结果与构建收据保存在本机 `.tmp/web-ui-20261115/`。iPhone 18 Pro / iOS 27.2 模拟器签名 Debug 构建与覆盖安装成功，Runner／Debug dylib／Dart内核哈希一致，5个持久化文件在安装后首次启动前逐字节保留。实际聊天中已检查玻璃标题／页签／输入区、正文过程记录、Skill／权限／上下文入口、模型目录直接显示及重复打开、输入折叠和工作台文件目录；没有点应用变更当前模型。Android 构建入口因未配置 SDK／可用 Java 而停止，ADB不可用，Lenovo真机未更新。模拟器和合成回归不能替代iPhone真机及所有provider验收。

## Consequences

原生界面使用网页的布局与操作位置，同时保留用户指定的玻璃。缓存消除同一连接、同一身份作用域内反复拉取目录的等待；容量上限为8项，五分钟失效，重连／账号／工作目录／目录身份变化后不能复用。代价是首次进入聊天多一次只读预取，并需要维护目录身份与Flutter／网页布局的对照；冷启动及显式刷新仍受桌面和上游耗时影响。缓存只影响展示，写入继续由原生即时核验，未知写入不重放。全量源文件审计见[页面对照](../../../../docs/ui-parity.md)，未对所有真实业务页宣称逐像素相同。

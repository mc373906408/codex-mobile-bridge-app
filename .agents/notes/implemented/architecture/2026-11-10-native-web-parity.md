# Agent Note: 原生 App 完整接入桌面 Web 业务能力

Status: implemented

后续[通用 HTTP 转发](2026-11-10-http-forwarding-without-route-policy.md)按用户要求移除各链路接口和方法清单；业务能力、身份与存储约定继续有效。

## Problem

App 的三种 provider、布尔审批和简化消息无法表达桌面 Web 的独立实例、工作台与管理能力；加密通道仍受早期接口清单限制。仅补按钮会丢失身份或错误地回落默认客户端。

## Decision

按用户确认的全量移植计划保留 Flutter 页面、Rust 协议核心和三标签导航。云账号只有登录；注册与激活码兑换属于桌面。业务按客户端/实例/执行主机/会话/账号隔离。默认实例保留旧序列化作用域，存储事务升级保留 v3 数据和未知操作；新功能使用显式资源、操作类型及受限参数，不能暴露任意 URL 或 IPC。本篇状态描述已落地的架构，不表示全功能或平台验收已完成。

工作台、会话管理和账号管理由独立控制器承担，写入前重新核验身份并持久记录，响应丢失不重放。HTML/Mermaid 只读预览使用隔离本地资源，所有进程仍在网关执行。

账号管理复用网关已有账号 ID、`managementRevision` / `modelCatalogIdentity` / WSL `identity`；不扫描本机配置，不新增一套账号指纹。Codex 公开现有 `AccountInfo.source_stamp()` 为管理版本。客户端将版本与网关授权身份、family、entry 组合为不透明比较值；其用途是拒绝切账号后的旧写入和迟到读取，不是设备指纹或生物识别。能力未知、实例消失、缺少管理版本均明确报错。

SQLite v5 在同一事务中增量建立草稿 options 和 `operation_authority`。后者单独保存写入时的网关授权身份，账号切换后可以核对原编码账号下的未知结果，但不能借新云账号读取旧网关的创建记录。普通刷新只读取，不激活原生会话；手动核对标记不等于操作成功。WSL 条目在管理页按原生与 WSL 分别开关，会话列表仍使用 family 下的环境身份。

文件下载按 Range/If-Range 分段写入临时文件，验证强 ETag、偏移和总长度；完成文件以唯一名称置于账号作用域的 ready 目录，Android/iOS 系统保存只接受该目录中的普通文件。恢复不接受变化后的内容。终端复用 HTTP 轮询和输入回执，句柄随工作台作用域保存；失效句柄必须先在电脑核对，再显式清除本地记录。

聊天阅读位置、工作台页签、已读标记和结构化消息引用保留完整会话与账号身份；列表的新活动使已读失效。已读验证最多四个并发被动请求，迟到核验不得覆盖更新后的列表。宽屏提供聊天和工作台并排，显示选项通过继承状态控制正文、代码字体与密度、思考/过程/截图等内容。

HTML 以无脚本 sandbox iframe 展示，Mermaid 使用随包资源和随机 nonce；CSP 拒绝外部资源、连接、表单和设备权限，预览不持有 Rust 凭据或业务桥。源文件和 Markdown 使用原生渲染，完整消息复制读取分页详情并核对版本。

业务页错误复用既有中英文错误白名单，原生堆栈和未知网关诊断不进入页面或终端状态栏；错误页可滚动且保留重新读取按钮。手机实测的旧网关会拒绝新账号接口，不能将这个拒绝伪装成空账号列表，也不能通过自动回放或放宽鉴权绕过。

## Alternatives considered

- 整体复用 Web 页面能快速达到展示一致，但用户选择原生业务页面，因此只在内容预览使用隔离 WebView。
- 将实例编码进 provider 或执行主机可少改字段，但会混淆独立配置和 SSH/WSL 主机，选择显式 entry 并保留默认作用域编码。
- 清空旧缓存能避免迁移，但会丢失已安装手机的草稿和未知写入，采用事务增量升级。
- 独立扫描配置生成账号指纹可以发现文件变化，但重复网关已有身份、易产生不同判定；使用网关现有版本并保留过期操作检查。
- 仅依赖模拟 Repository 能更快运行 UI 测试，但无法验证 HTTP 字段、原生序列化和 FFI。CI 固定检出 `toolchains.json.gateway_commit`，缺少桌面夹具即失败。

## Testing

逐项结果见[验收矩阵](../../../../docs/web-parity.md)。Rust 81 项通过、1 项专用 P2P 夹具跳过；实际 DLL 的既有 FFI 8 项通过，新增桌面 HTTP 契约覆盖真实临时 Git 仓库、消息分页、Range/ETag、ZIP、终端回执、项目和账号变化。客户端驱动是合成夹具，不能替代实际 Codex/Claude/DeepSeek/ZCode 验收。Flutter 全量 402 项通过、4 项原生入口在普通运行中跳过，实际原生入口另行运行。16 张变化的浅深色截图逐张审核后更新，窄屏中英文大字体和审批可选决定有专门回归。构建/验收脚本 94 项中 2 项 macOS 专用跳过，其余通过。[审核准备](../../../../docs/app-store-readiness.md)记录原生演示、测试环境与当前规则核对，仍需真正可用的环境及 iOS 签名设备证据。

## Consequences

架构支持原生工作台、管理与完整消息语义；代价是管理写入和账号敏感读取需要额外身份请求，设备、客户端和三条传输的组合验收仍较大。Lenovo L71091 同签名覆盖安装成功，首次启动前 28 个私有文件逐字节保留，真实 v3→v5 升级保留 1 台电脑、6 条草稿、1 条操作记录及通知同意；原连接可读取 Codex 会话和工作台。错误页修订包再次安装前后的 36 个私有文件一致。桌面授权更新后账号管理可读取，实际返回 0 个 Codex 已保存账号，不能据此认定额度和切换通过。iOS 普通/cloud 构建与签名设备、真实 PTY/IME、传输恢复、预览隔离的设备证据分别记录在矩阵，不用组件通过代替。云未上线允许协议破坏性调整，仍不允许删除现有测试手机的草稿、凭据和未知写入。许可证与 P2P 继承改动保持其原有归属。

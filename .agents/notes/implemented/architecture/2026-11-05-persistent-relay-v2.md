# Agent Note: 手机持久中继与恢复状态

Status: implemented

## Problem

每请求重新握手与每轮目录重新配对扩大失败机会；目录/资格读取失败会清除聊天认证。用户确认系统整改、三端同步升级，并最终要求取消客户端资格自动刷新。

## Decision

可选直连及云断开时的权限保留由 [EasyTier P2P](2026-11-06-easytier-p2p.md) 扩展；本篇仍持有中继流控和未知写入不重放规则。

Rust 按绑定与凭据代次管理持久 Noise 会话、8 个逻辑流、4 块窗口、统一心跳与重连。Flutter 分离目录、连接和明确授权状态。客户端资格仅显示和显式查询，不控制官方服务器放行。续期持久化 request_id，恢复同一次轮换结果。预览、安全码、账号、草稿和操作记录保留；未知写入不自动重放。后台停止只读会话和保活，前台按需恢复。

## 记录归属

[响应完成](../../implemented/bug-fix/2026-11-04-relay-response-completion-and-recovered-errors.md)部分重叠，保留完整响应/截断的判断；[云状态边界](../../implemented/bug-fix/2026-11-04-cloud-state-boundaries-and-legacy-removal.md)继续持有身份和原生通知隔离；已有 proposed 聊天恢复笔记部分重叠，保留界面提示来源隔离。协议规范及三端验收由服务端同名持久中继笔记持有。

## Alternatives considered

仅清除错误横幅不能恢复连接。扩大重试会重复握手并可能重放写入，因此连接恢复与业务重试分开；已提交写入继续人工核实。

## Testing

真实 Go/Python/Rust/Dart 业务阶段 1800 秒完成 107648 次读取，一次业务握手；首次配对证明单列，不伪装为零额外握手。独立 fault4 测试通过 SSE/通知/列表和 20 MiB 文件并发、心跳、自动恢复、20 次监听取消、20 MiB 上传和未知写入不重放。Rust 66 项通过；Flutter 完整 suite 和实际生成 DLL 的 7 项 FFI 通过。客户端持久化同一个刷新 request_id、丢响应后新 manager 恢复及存储失败阻断网络均有测试。原始失败和有效结果保存在 `D:/github/.codex-tools/relay-v2-20261105/`。

运行已提交写入时，普通后台暂停最多等待 60 秒收尾；账号退出、换凭据和显式撤销立即关闭旧会话。连接状态订阅有显式取消 FFI，结束页面不能留下等待状态变化的原生任务。测试手机覆盖安装与 iOS 能力在交付结果单列。

首轮真机列表可读，但恢复时并发认证会短暂清空认证状态并留下“登录失效”提示。认证结果现绑定真实加密会话代次，同一代次内复用认证，新代次必须重新读取 `/api/auth`；恢复中的只读快照等待该次认证，不把连接重建误报为账号失效。真实 FFI 夹具并发执行认证、snapshot 和 pending-creations，断言 `/api/auth` 次数不增加且读取身份持续有效。

## Delivery

2026-11-05 最终 Android ARM64 debug APK SHA256 为 `ea5fd5badba33b05f68846f4e7685cc9b2e1373686803bedf608addaad0e7329`，355 个源码/配置文件构建前后哈希一致，锁文件与生成绑定未被构建改写，签名、ELF/ZIP 对齐及服务端秘密排除通过。同签名覆盖 Lenovo L71091 后，安装包哈希一致、原始安装时间保留、9 个数据库/凭据/通知配置文件在启动前保持哈希；没有卸载、清数据、退出真实账号或重新配对。

最终真机连续三次刷新、后台回前台、进入当前聊天再返回列表均无网络/登录失效横幅或配对页；截图和逐步 XML 在 `.tmp/relay-v2-20261105/`。后台通用密文推送尝试一次后服务端状态 `acked`，系统通知记录包含本轮通用测试文字；没有向真实聊天写入。Flutter 318 项、Rust 66 项、实际 DLL FFI 7 项、真实跨端混合故障测试与 clippy/analyze 通过。iOS 只通过静态构建图检查（169 objects），没有 Xcode、签名或真机验收，不计为 iOS 交付完成。

## Consequences

持久会话与目录故障隔离减少连接重建和错误连带，代价是流生命周期与会话生命周期分离。连接恢复不恢复旧控制快照，必须读取新状态后才启用操作。客户端资格仅显示，不参与官方授权；没有自动查询时显示值可能滞后。iOS 签名/设备验收独立报告，不能用 Windows 测试替代。

# Agent Note: 云聊天读取恢复与提示作用域

Status: proposed

## Problem

手机在聊天列表持续显示网络中断和账号身份无法核验。实际网关在线，相关聊天 timeline 返回有效 `draftAccountIdentity` 和原桌面连接；手机运行时也捕获到有效身份的快照，同时设备检查恢复 active 后 `auth` 仍为空、订阅已取消。现有 `cloudAccessChanged` 只处理关闭，不处理已连接设备的检查恢复。

另有独立的提示残留：`_applySnapshot` 仅在非空时写 notice，身份恢复不会清除旧警告；`backToSessions` 不清理聊天的 notice 和订阅读取错误；无账号身份的只读快照提前返回，不能清除已恢复的订阅网络错误。列表内容存在不能证明这些旧提示仍描述当前状态。

## Proposal

聊天快照持有自己的 notice 和读取错误，成功的后续快照仅清除自身旧提示；离开聊天清除已结束订阅的读取提示，保留结果未知、草稿失败等其他来源。无身份快照仍只读，恢复传输不授予写权限。

设备发现短暂读取失败时立即停止控制，保留“此前已经认证、等待同一身份核验”的恢复意图；只有同一账号、绑定、公钥、有效服务和桌面许可重新验证后，才重新读取认证、列表和原聊天快照，重新订阅。明确撤销、账号退出、身份变化、切换电脑、返回首页和后台均阻止迟到恢复。重连不发送消息、审批、停止或重放任何未知写入。

## 记录归属

[已认证聊天能力](../../implemented/bug-fix/2026-11-11-authenticated-chat-capabilities.md)修复可选编码账号标识缺失导致的额外拦截；本篇恢复流程以网关授权身份是否有效为前提，编码账号标识不再作为关闭聊天能力的条件。

检索身份、错误、恢复与中继活跃笔记后，[中继响应与已恢复错误](../../implemented/bug-fix/2026-11-04-relay-response-completion-and-recovered-errors.md)部分重叠，继续持有完整响应和按来源清理错误；[连接列表](../../implemented/bug-fix/2026-11-05-connecting-conversation-list.md)继续持有连接期间展示；[云状态边界](../../implemented/bug-fix/2026-11-04-cloud-state-boundaries-and-legacy-removal.md)继续持有加密核验、原生封锁和权限缩减。本篇补上已连接聊天的恢复及提示生命周期，没有完全吸收或归档记录。

## Alternatives considered

- 每次列表读取成功清除全部提示简单，但会掩盖未知写入及草稿存储失败；只清理所属读取的提示。
- 设备检查失败时继续使用旧授权可隐藏断线，却放宽了现有安全边界；仍立即封锁，重新核验后仅恢复只读连接。
- 一律让用户退出重登可重新建立状态，但丢失原因、增加交互且可能不解决旧 notice；在准确身份范围内恢复已有认证读取。

## Acceptance criteria

复现并覆盖无身份→有身份、订阅断线→只读快照、返回列表、更新错误保护；覆盖设备检查失败→同身份恢复、明确撤销与换钥、迟到重连、草稿及未知写入保留。通过必要源码、真实 FFI、构建和覆盖安装检查，在手机实际聊天详情、刷新和前后台恢复中核对有效身份、订阅与错误状态。

## Risks

实际网络仍可能失败；恢复不能无限重试写入或把历史身份当新授权。真机及合成验证须分别报告，不能以静态分析或列表加载代替长连接和身份恢复证据。

# Bridge Mobile 0.1.0

首个 GitHub 下载版本。连接自己的桌面网关，在手机上查看 Codex、Claude Code/Cowork、DeepSeek 聊天，发送消息和附件、处理审批并查看任务状态。支持直连、端到端加密云中转、中英文及浅色/深色主题。

## 下载与安装

- **Android 8.0+**：下载 `bridge-mobile-v0.1.0-android.apk`，允许当前下载来源安装应用后打开 APK。使用独立发布证书签名，包含 ARM64、ARMv7 和 x86_64。
- **iOS 15.0+**：下载 `bridge-mobile-v0.1.0-ios-unsigned.ipa`。此文件**未签名，需要使用自己的 Apple ID/开发者签名，通过支持的侧载工具签名后安装**；不能直接点击 IPA 安装，也不是 TestFlight 或 App Store 包。签名有效期和设备限制取决于所用账号与工具。
- `SHA256SUMS.txt` 提供下载校验值；`android-build.json`、`ios-build.json` 记录源码提交、工具链和构建产物信息。

首次使用请先安装并配置[桌面网关](https://github.com/mc373906408/codex-mobile-bridge)。使用云端时，在桌面端完成注册，手机登录同一服务器和账号，然后在电脑上允许这台手机连接。

## 当前版本说明

- 发行包采用普通版本：支持直连和云中转；不包含 Android 厂商推送 SDK 或 iOS APNs 通知扩展。Android 后台提醒依赖系统通知权限与前台消息服务，iOS 后台云推送尚未随本包分发。
- Android 发布证书与旧开发测试包的 debug 证书不同。若曾安装开发包，不能直接覆盖，卸载会清除该 App 的本地数据，操作前请确认需要保留的信息。
- 旧开发版数据库不支持直接迁移到当前格式；首次正式版本从当前存储结构开始。
- 构建和自动化检查不代表所有手机型号或真实推送场景均已验证。签名 iOS 分发与真机验收仍需独立完成。

# Bridge Mobile 0.2.0

本版改进云中继的连接稳定性和恢复行为，采用持久加密会话，减少聊天、列表和附件读取时反复建立连接带来的失败。

## 主要变化

- 同一设备绑定复用 WebSocket/Noise 加密会话，多个请求独立传输；请求完成或取消后释放对应流。
- 增加心跳、退避重连与连接状态订阅，恢复后重新读取聊天并恢复订阅；结果未知的写入不会自动重发。
- 设备目录短暂查询失败不会撤销已验证连接，区分连接中、桌面离线、服务到期和版本不兼容等状态。
- 取消手机和桌面端的服务资格定时查询；官方服务器继续独立检查资格、到期时间和撤销状态。
- 登录续期支持同一请求恢复，改进云通知默认状态、连接时的列表展示以及已恢复错误提示的清理。

## 云中继升级要求

`bridge-relay-v2` 需要三端配套升级。使用云中继时，请同时更新[桌面网关](https://github.com/mc373906408/codex-mobile-bridge/commit/e142f6d771303769932fbf5c9c0d00da902591b1)和[云服务端](https://github.com/mc373906408/codex-mobile-bridge-server/commit/f6e0a7f46e4975e052ad7e8ae777d6f100093285)，或采用包含这些提交的后续版本。旧版中继协议会被明确拒绝；本地直连仍沿用已有 HTTP 接口。

## 下载与升级

- **Android 8.0+**：下载 `bridge-mobile-v0.2.0-android.apk`，包含 ARM64、ARMv7 和 x86_64，版本号为 `0.2.0`、构建号为 `2`。沿用 0.1.0 的发布证书，可覆盖升级同签名正式包并保留本地数据。
- **iOS 15.0+**：下载 `bridge-mobile-v0.2.0-ios-unsigned.ipa`。该 IPA **未签名**，需使用自己的 Apple ID/开发者签名及兼容侧载工具处理；不能直接点击安装，也不是 TestFlight 或 App Store 包。
- `SHA256SUMS.txt` 提供下载校验值；`android-build.json` 和 `ios-build.json` 记录源码提交、工具链及产物信息。

公开发行包沿用普通版本：支持直连和云中继，不包含 Android 厂商推送 SDK 或 iOS APNs 通知扩展。开发测试手机上的推送试验包使用独立 debug 签名，不能直接覆盖为公开发行包；请勿通过卸载来完成需要保留数据的更新。

两平台构建与检查通过后才发布下载附件。自动检查不能替代 iOS 真机、Apple 签名与所有手机型号的兼容性验收。隐私与权限见[隐私说明](https://github.com/mc373906408/codex-mobile-bridge-app/blob/main/docs/privacy.md)。
